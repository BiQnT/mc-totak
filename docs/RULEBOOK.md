# 📜 총학생회 영지 마인크래프트 서버 — 룰북 v1

> 본 룰북은 게임 메커니즘이 아닌 **룰·Discord 권위로 영지 위계를 강제**합니다. 위반 시 운영진 판단에 따라 경고/롤백/추방 조치가 가능합니다. 첫 접속 전 반드시 한 번 읽어주세요.

## 2. 평화기 (Peacetime)

- PvP 비활성 (WorldGuard 글로벌 region `pvp deny`)
- 농사·자원 채집·건설·외교 자유
- 영토 청크는 Towny `/town claim` 으로 점유 (1국서당 한도 내)
- 비공식 외교(Discord, 채팅)는 자유

## 3. 학기말 전쟁 — SiegeWar 선포 절차

v1은 학기말에 **단 1회**의 공식 SiegeWar 충돌만 가집니다.

### 3.1 영주국 → 영주국 전쟁
1. 선포 측 leader가 Discord `#전쟁선포` 채널에 의도 발표
2. **황제국(회장단) 승인 필요** — 회장단이 적합성 판단. 부적합 시 거부 가능 (이유 명시)
3. 승인 시 SiegeWar 콘솔로 siege 개시. 준비기간 4일
4. 정해진 시간대(2~4시간 윈도우)에 충돌. 결과는 운영진이 공식 발표

### 3.2 영주국 → 황제국 전쟁 (반란 시나리오)
1. **황제 승인 불필요** — 영주국 단독 또는 다수 영주국 연합으로 자유롭게 가능
2. 다른 영주국은 자유의지로 황제 측 또는 반란 측 가담
3. 황제국 함락 시: 시즌 종료까지 황제 위상 공석

### 3.3 황제국 → 영주국 전쟁
- **원칙 금지.** 영주국의 명백한 룰 위반 또는 불복종이 있을 때 운영진 협의 후 가능

## 4. 가담 룰 (Joining a Siege)
- 영주↔영주 충돌에서 제3 영주국은 자유의지로 어느 측에든 가담 가능
- 반란(영주 → 황제) 충돌에서도 동일
- 가담 결정은 SiegeWar 콘솔 명령으로 명시. Discord 공지 권장

## 5. 그리핑 처벌 + CoreProtect 롤백

### 5.1 그리핑 정의
타국 영토에서 무단 파괴/약탈/표시. 평화기 PvP 외 침해, 전쟁기 SiegeWar 룰 외 침해.

### 5.2 신고 절차
1. 피해자가 Discord `#그리핑신고` 채널에 좌표·시간·증거(스크린샷) 제출
2. 운영진이 `/co lookup` 으로 행위 기록 조회
3. 가해자 확인 시 운영진이 `/co rollback u:<player> t:<time>` 롤백

### 5.3 처벌
- 1차: 경고 + 롤백
- 2차: 24시간 ban + 롤백
- 3차: 영구 ban

## 6. 회장단 player-admin 권한 분리 룰

회장단 멤버 1명이 admin + emperor 권한 동시 보유. 권력 남용 방지를 위해:

- **자국 플레이 시간**: emperor 그룹 권한만 사용. admin 명령 (`/op`, `/give`, `/teleport <other>`, `/gamemode creative`) 미사용
- **운영 개입 시**: Discord `#운영공지` 채널 사전 공지 후 실행. 사후 로그 권장
- **자국이 SiegeWar 당사자일 때**: admin 권한 일시 중단 (다른 회장단 멤버에게 위임). 결과 발표·중재는 다른 운영자

## 7. 운영진 권한 (admin)
- `/op`, `/co`, `/region`, `/lp` 등 시스템 명령 자유
- 그리핑 신고 처리, 룰 위반 판정, 전쟁 결과 공식 발표
- 운영진 결정 불복 시 Discord `#이의제기`

## 8. 운영 안정성 (Reliability)

- 자동 백업: 매일 04:00 KST. 30일 보관
- 의도치 않은 다운타임: 누적 24시간 이내 (학기 전체)
- 백업 복구 시도 시 운영진 합의 + Discord 공지
