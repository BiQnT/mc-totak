# 📜 총학생회 포켓몬 도장깨기 서버 — 룰북 v1

## 1. 도장 도전 룰
- 11 도장이 맵에 분산. 각 도장은 도장관(운영진/임명 학생) 보유.
- 도전자: 도장관에게 `/pokebattle <도장관닉네임>` → 6대6 배틀 또는 도장 자체 룰 (3대3 등)
- 승리 → 배지 1개 획득
- 11 배지 → 챔피언 도전권
- 챔피언 = 회장단. 학기 종료 1주 전 토너먼트로 우승자 결정

## 2. 배틀 룰
- 본인 파티 외 다른 학생 포켓몬 빌리기 금지
- 임의 종료(연결 끊기, 강제 종료) → 자동 패배 처리
- 배틀 중 외부 도움 (다른 사람 명령 받기) 금지

## 3. 그리핑 / 트롤링
- 다른 학생 영토에서 무단 파괴, 포켓몬 훔치기 금지
- 신고: Discord `#그리핑신고` (좌표 + 시간 + 증거 스크린샷)
- 처벌: 1차 경고 + 롤백 / 2차 24h ban / 3차 영구 ban

## 4. PC / 보관함
- `/pc` 로 본인 보관함 접근. 다른 학생 PC 접근 금지.
- 야생 포켓몬은 누구나 잡기 가능. 도장관 소속 포켓몬은 trainer-only.

## 5. 운영진 권한
- `/op`, `/co`, `/pokegive` (운영진만), 트러블 발생 시 개입
- 운영진 권한 사용 시 Discord `#운영공지` 채널에 사유 기재

## 6. 운영 안정성
- 자동 백업: 매일 04:00 KST. 30일 보관
- 서버 다운타임 누적 24시간 이내 (학기 전체)
