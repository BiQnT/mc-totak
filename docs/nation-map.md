# 🗺️ 9 Nation 좌표 맵

월드 spawn `(0, 64, 0)` 중심 반경 ~2500블록. 회장단(황제국)은 spawn에서 약 1500블록(정북) — 황제 위상 반영.

## 좌표 표

| 순번 | 국서 | 위상 | x | z | 방위 |
|------|------|------|----|----|------|
| - | (월드 spawn) | 중심 | 0 | 0 | 시작점 |
| 0 | 회장단 | 황제국 | 0 | -1500 | 정북 (가장 안쪽) |
| 1 | 사무총괄국 | 영주국 | 2500 | 0 | 동 |
| 2 | 재정관리국 | 영주국 | 1768 | 1768 | 남동 |
| 3 | 대외협력국 | 영주국 | 0 | 2500 | 남 |
| 4 | 미래전략실 | 영주국 | -1768 | 1768 | 남서 |

## 영토 한도
- v1 기본: 국서당 최대 청크 64개 (`bonus_block` 추가는 운영진 판단)
- AC 임계값: 학기 종료 시 1국서가 전체 영토 청크의 < 40%

## 거점 답사 권장 좌표
스폰에서 명령어로 확인:
```
/tp 0 100 -1500  → 회장단 후보지
/tp 2500 100 0   → 사무총괄국 후보지
/tp 0 100 2500   → 대외협력국 후보지
... 등
```

좌표가 부적합한 biome(예: 깊은 바다)이면 ±200 미세 조정 후 운영진이 `/town setspawn` 으로 확정.
